# fonts

本目录记录扩展中直接使用的开源字体来源与许可证。

当前直接联网加载：

- **霞鹜文楷 GB / LXGW WenKai GB**
  - 官方项目：https://github.com/lxgw/LxgwWenkaiGB
  - 许可：SIL Open Font License 1.1
  - 扩展加载：官方项目 TTF，经 jsDelivr GitHub CDN

- **霞鹜臻楷 GB / LXGW ZhenKai GB**
  - 官方项目：https://github.com/lxgw/LxgwZhenKai
  - 许可：SIL Open Font License 1.1
  - 扩展加载：官方 GitHub Release 原始 TTF

其余方正、汉仪、华康、Aa 等字体只保留 font-family 名称，不在本公共仓库重新分发字体文件。
