# 在安卓模拟器里真跑本扩展（2026-10-20 趟通）

手机上什么样，模拟器里就什么样；还能直接读页面报错、替用户点按钮发消息。命令都在本夹里跑（`cd` 到本夹）。

## 一次性准备

1. 开模拟器：`pwsh -NoProfile -File "E:\个人AI资源管理\60_公用资源（钩子·skill·搜索引擎·可后期扩展）\设备模拟器（多agent共用·测应用）\01_安卓（Google Emulator）\脚本\一键启动并等开机.ps1"`（看到 `BOOT_OK`）
2. 手机酒馆：`E:\个人AI资源管理\40_下载资产（…）\TauriTavern手机酒馆（安卓模拟器测插件用）\` 里的 arm64 安装包，用同夹 `脚本\装APK.ps1` 装（模拟器是 x86_64，但带 arm64 转译，能跑）。包名 `com.tauritavern.client`。10-20 起已经装好，里面有：本扩展、酒馆助手、提示词模板、陆雪琪 / 仙侠小说 / 果子姐三张卡、Gemini 3.8 flash 连接
3. 接调试口（每次重开手机酒馆 pid 会变，要重接）：
   ```
   adb shell pidof com.tauritavern.client
   adb forward tcp:9333 localabstract:webview_devtools_remote_<pid>
   ```
   `adb` 在 `E:\AndroidSdk\platform-tools\adb.exe`

## 常用

| 要干啥 | 命令 |
|---|---|
| 在页面里跑一段 JS | `node cdp.mjs eval "return SillyTavern.getContext().name2"` / `node cdp.mjs file x.js` |
| 截图 | `node cdp.mjs shot a.png` |
| 录报错（可带 reload） | `node logs.mjs 60 reload` |
| 发一句、等回完、看变量和变量小框 | 把 `globalThis.__msg='…';` 拼在 `turn.js` 前面再 `node cdp.mjs file` |
| 打开卡时那些「要不要启用脚本 / 正则」弹框全点确定 | `node cdp.mjs file okpops.js` |
| 导一张 png 卡（连世界书） | `node pngbook.mjs 卡.png 卡.card.json` 再 `node impcard.mjs 卡.png 卡.card.json` |
| 换模型 | `node setapi.mjs "清单里平台名的几个字" "模型名"`（钥匙从 E 盘模型清单读，不打印）；model 没换上就在页面里直接设 `chatCompletionSettings.custom_model` |
| 改了扩展代码推进模拟器 | `adb push 文件 /storage/emulated/0/Android/data/com.tauritavern.client/data/default-user/extensions/tt-chat-ui-controls/`，再 reload |
| 变量小框读路径的离线测试 | `node t-mvu.mjs` |

## 坑

- 新装的手机酒馆开头有个「起用户名」欢迎框，不点确定就一直卡在「启动中：加载扩展」
- 默认回复长度 300，中文正文一长变量块就被截断（看着像 MVU 没认），测之前调到 3000
- 打开带脚本的卡会连弹好几个确认框，`selectCharacterById` 一直等着不返回，先跑 `okpops.js`
- `EmbeddedRuntimeManager.invalidate … slot not found` 这条页面报错是手机酒馆自己的，停用本扩展照样出（10-20 对照过）
- Git Bash 里 adb push 路径前要 `MSYS_NO_PATHCONV=1`，不然 `/storage/...` 被改成 Windows 路径
