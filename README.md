# 聊天显示控制 v1.6（SillyTavern / TauriTavern）

目前包含三类控制：

1. **聊天正文颜色**：只改消息正文。
2. **聊天正文字体**：在 UI 主题页直接下拉切换。
3. **背景图片模糊强度**：只模糊最底层背景图；原生“模糊强度”继续作为 UI 模糊。

## 字体

v1.6 现在随扩展提供 **8 款实际字体文件**，不是只有名称的假选项：

- 思源宋体（常用阅读）
- 寒蝉锦书宋（温润宋体）
- 文津宋体（古典正文）
- 霞鹜文楷 GB（舒展）
- 霞鹜臻楷 GB（较厚实）
- 清松手写体1（圆润）
- 小赖字体（圆润手写）
- 悠哉字体（轻松手写）

保留“跟随主题”。选择字体时按需从扩展自己的 `fonts/` 目录加载，不依赖手机系统字体，也不访问第三方字体 CDN。现有四款保持 WOFF2；新增四款保留官方 OTF/TTF 原格式，避免大字库二次压缩造成构建时间过长。

> 犬仓书楷已经确认是 OFL 1.1、允许嵌入和再分发，但目前作者/收录站公开下载主要走夸克网盘，没有稳定的官方直链可用于仓库自动构建，所以这次没有冒险抓第三方不明镜像。等拿到原始字体文件后再补入。

## 使用位置

TauriTavern：

**用户设置 → UI 主题 → 聊天正文颜色 / 聊天正文字体 / 背景图片模糊强度**

首次选择某款字体会显示“正在加载”，成功后立即切换已有聊天正文，无需再次刷新。

## 更新

仓库安装地址：

`https://github.com/ardenbright8-coder/tt-chat-ui-controls.git`

已经安装旧版时，在扩展管理中对“聊天显示控制”执行更新即可。

更新完成后刷新页面一次；独立 App 可关闭后重新打开。
