# 酒馆拓展 v1.18.20（SillyTavern / TauriTavern）

目前包含三类显示控制、一套手机版防误触，以及移动端世界书界面优化：

1. **聊天正文颜色**：只改消息正文。
2. **聊天正文字体**：在 UI 主题页直接下拉切换。
3. **背景图片模糊强度**：只模糊最底层背景图；原生“模糊强度”继续作为 UI 模糊。
4. **手机版防误触**：滑块必须明确横向拖动才改值；单点、轻触和上下滚动不改值。用户设置里的布尔开关在手机端改为长按确认：单点不改值，在复选框上静止长按约 500ms 才切换。
5. **世界书移动端 UI**：把官方 World Info 现有 DOM 在手机上重排为卡片列表、单条常用编辑、高级参数折叠和长文本专注编辑。
6. **阅读旧消息时保持位置**：向上翻阅后发送消息时，挡住聊天自动跳底；一旦手指、鼠标或键盘开始手动翻阅，立即解除本次位置保护，随时都能继续上下滑动。若发送时已在底部，沿用酒馆原有的自动滚动设置。切换聊天时解除位置保护。
7. **自动配图**：主模型每写完一条正文，交给另选的连接配置（如便宜的 DeepSeek）规划画面，再走酒馆自带「图像生成」画好，贴到这条正文末尾；每张角色卡带一本角色长相档案，同一个人每张图长一个样。主模型不用管出图，当前连接不切换。
8. **角色变量（v1.18.0）**：用 MVU 变量的角色卡，每条回复底下一个小框写这条改了哪些变量（「林婉茹 · 忠诚度 20 → 43 +23」）。AI 把变量更新写成光秃秃的 JSON 代码块、MVU 不认时，收到回复就自动包好 `<UpdateVariable><JSONPatch>` 标签，没算上再替你点「重新处理变量」；旧消息里坏掉的标红，最新一条能一键「修好并重新算」。扩展页「角色变量」两个开关都能关。（v1.18.1）≡ 菜单加「测试日志」：每条消息的变量处理过程、MVU 解析出几条命令、报错都记下来，能存到手机发给帮你改代码的 AI。（v1.18.3）输入框上面「重新处理变量」那排大按钮收进 ≡ 菜单「变量」；发送按钮上面加「深入」小圆钮（AI 留在这场戏里按人物内核写深一条，说明在扩展页「聊天按钮」能改）；（v1.18.4）「到最底下」改放 ≡ 菜单；深入说明改版：可以加服务这场戏的配角和小事，对话是表现人物的主力。（v1.18.20）输入框写了字再点「深入」：字照常作为你的消息发出去（留在聊天里能改了重发），再按深入写；变量小框那行太长时「展开」不再被挤掉。（v1.18.19）「深入」说明退回原版（第三版）；修好「深入」压住纸飞机（酒馆把那排每格定死 40px 宽，字溢出去了）。（v1.18.18）接管发送：输入框写了字点发送，带上「写好这一轮」照你写的走、写得好看；空着点发送，另起一条新回复、带上「往下走」，不再接着上一条续写（扩展页「聊天按钮」能关）。三段说明（深入 / 写了字发送 / 空着发送）都收进 ≡ 菜单「写法说明」，点一段进大窗口改。（v1.18.17）「深入」改成跟纸飞机一个样式（不要边框，同样的灰），跟发送按钮之间留出间距。（v1.18.16）「深入」挪进输入框那一行、发送按钮左边，做成带边框的胶囊，大一点；Agent 按钮默认藏掉（扩展页「聊天按钮」能关）。（v1.18.15）深入另起一条新回复，不再接着上一条续写；输入框里先写几句再点深入，会当成这一轮的临时补充带上，不作为你的消息发出去。（v1.18.14）深入说明换成第三版（短、通用、不刻意加东西）；深入按钮去掉放大镜，只写「深入」，在纸飞机正上方。（v1.18.13）变量小框压缩：没改变量的回复不显示；正常的只留一行「变量 · 林婉茹忠诚度 +3」，点一下才展开；没算上才整个摊开标红。（v1.18.5）总结带上当时的变量数值，「替换开场白」开新聊天时一起带过去；总结库里能给旧总结「带上现在的数值」。（v1.18.6）「深入」改放输入框上面的「快捷工具」一排，灰色小按钮；总结库能「看数值」。

## 自动配图（v1.9.0 起；v1.10.0 加长相档案）

位置：**扩展 → 自动配图**（扩展设置列表里的一个折叠栏）。

前提：
- 「图像生成」扩展已能出图（ComfyUI 等任一来源）。
- 「API 连接」里存好一个写画图词用的连接配置文件或「模型」（例如 DeepSeek V4 Flash）。

设置：
- **每条正文自动配一张图**：开关，默认关。（v1.17.5）魔法棒里也有一项「打开自动配图（现在关着）／关掉自动配图（现在开着）」，点一下就切，跟这里是同一个开关。
- **新角色出场后补一张定妆照**：默认开。（v1.12.0 起）先画这条的配图，配图贴好、又没有新消息排着时才画定妆照；定妆照不进聊天，只在魔法棒「看定妆照」里看，带点情欲感（露肩、乳沟、勾人的笑）。
- **画图时不弹「正在生成图像…」提示**：默认开，出错的红色提示照常显示。
- **聊天里的图铺满气泡，点图不放大，图上只留右上角「存到手机」**：默认开。点了把这张图存进手机（走酒馆自带的导出，安卓上一般在「下载」里，存完会弹提示）。酒馆自带的两排图片按钮（上面放大 / 说明 / 删除，下面「< 1/1 >」翻图）都藏起来；手机上字和图都铺到气泡最右边，最后一条消息底下留出位置，右下角的「>」重新生成和「1/1」在内容下方、不被盖住（v1.16.0）。（v1.15.6 去掉了「改词重画」画笔：只重画一张用不上，要改以后每张图怎么写走魔法棒「改配图提示词」）**一条消息只留一张图**：重新生成、手动再配一张，都是换掉旧的。
- **写画图词用哪个连接配置**：跟「API 连接」页那个下拉框是同一批（连接配置文件 + TauriTavern「模型」两类）。只用来写画图词，不切换正在聊天的连接。
- **角色长相（这张角色卡的，v1.15.8 起在魔法棒「看定妆照」里）**：一张角色卡一套，新开聊天也是这一套（群聊还按聊天存）。每个角色一行——定妆照缩略图、英文长相标签（可直接改）、「想怎么改」中文输入框、「按这个改，再出一张定妆照」、「删掉这个角色」。
- **写词套装**（v1.11.0）：内置 5 套——① 默认·国风情欲 ② 更放得开 ③ 唯美含蓄 ④ 整句描述（多人不串，按 Anima 官方建议整句 + 标签混写）⑤ 镜头感。每套 = 公共规则（回 JSON、长相照档案、必须写镜头、默认明亮）+ 这套自己的画面写法。
- **写词说明**（v1.15.4 起归你）：当前这套的英文提示词，可改，点「保存」存在手机里（v1.16.5 起，以前是边打边存）；每套内置的（现在 7 套）各存一份你自己的，换套装、更新扩展都不会动它。想要扩展里新写的版本，在那套上点「恢复原版」（会先问一句）。「复制一套」起名留着，也能删。
- **左下角魔法棒 →「改配图提示词」**（v1.15.4）：弹窗里直接改上面这块，跟扩展设置里改的是同一份。
- **给最后一条正文配一张**：手动补图，不看开关。

流程：
1. 收到主模型的新正文（续写、扮演、后台和扩展自己发的消息不算），去掉状态栏 / 变量更新块 / HTML。
2. 连同「已知角色长相」、角色卡描述、用户上一句，发给写词模型，要它回 JSON：`skip`、`rating`、`people`（从左到右，名字 + 性别）、`new_looks`（只给档案里没有的新女角色设计长相）、`scene`（衣着、表情、动作、地点、光线，不含长相）。
3. 回的不是 JSON → 自动再问一次（v1.15.1）；两次都不对才不画，黄色提示里带上它回的前 80 个字，方便查是拒绝、空回复还是格式写歪。`skip: true` → 这段不画。
4. 新角色写进长相档案（v1.15.8 起存在扩展设置 `autoImageCastByChar` 里，按角色卡头像文件名分；以前存在聊天 metadata `tt_autoimg_cast` 里的，打开那段聊天时并进来），（定妆照放到第 6 步之后画）。
5. 画图词 = 尺度 + 人数 + **档案里的长相原样照抄** + 场景 + 明亮光线；多个女角色时用「左边 / 右边那个女人有……」把长相绑在位置上；3 人以上长相只留发色发型、眼睛、胸型、记号。上限 1800 字符，超了先砍长相，**场景（动作、地点、光线）永远留全**——以前人一多场景被截掉，图只剩白底。
6. `/sd quiet=true` 出图，追加到这条消息的 media（`inline_image: true`，正文照常显示）。多条排队，一张画完再画下一张；**排队时来了更新的消息，旧的就不画了**，图只出在最新那条上。

写词说明的默认规则里（v1.13.0 起）：画面以女人为主，男人只在需要身体接触时出现，而且只用第一人称视角露手、腰和下体，不露脸、不画完整的男人（画图词里写 `pov, faceless male, male head out of frame`），不是亲热的场面男人不进画面；每张换体位和镜头。（v1.14.0 起）一张图只画这段最后、最要紧的那一刻，只画一个动作，原文没写的不加（扶她、百合、自慰、旁观这些）；这一刻在场的女人都画进去，同框最多 5 个（v1.15.0）；不选会让男人的背、胸、脸成为主体的构图（比如从外面看她从背后抱他），改成男人视角看她；地点必须带年代细节，故事不是明显现代就按古代国风写（木格窗、纸灯笼、屏风、帐子床），不许出现现代家具和电灯。成人恋爱向，日常场景也要有情欲感（至少 sensitive：露肩、乳沟、薄纱、勾人的眼神和姿势）；光线默认明亮温暖，只有剧情本身明显黑暗时才偶尔转暗，不要暗黑哥特。（v1.15.2 起）不加内容限制，画不画、画多露骨由写词模型自己判断。改长相时只改用户说的那几项，其余照抄。

图的横竖由生图那一端定（本作者的电脑面板默认横版 1216×832，铺满聊天气泡）。

注意：
- 图像生成里的「扩展自由模式提示词」不要勾，否则主模型会再改写一遍画图词。
- 长相靠文字描述锁定：发型、发色、眼睛、身材稳定，脸大约八成像；两个女角色同框偶尔会串。

## 手机版防误触与自动保存

仅在粗指针/触摸环境启用，PC 保持原来的鼠标交互。

- 滑块按下后先等待约 10px 的方向判断。
- 上下移动优先判定为页面滚动，本次手势直到抬手都不能再切换成调参。
- 横向移动必须明显占优（约为纵向位移的 1.2 倍）才进入滑块模式。
- 单点轨道、轻微触碰不会改变数值。
- 横向拖动时实时预览；手指抬起后自动提交一次最终值。
- 用户设置里的布尔开关采用长按确认：必须按住实际复选框约 500ms，且期间移动不超过约 10px，才切换一次并自动保存；单点、轻触、上下滚动均不改值。
- 数字输入框可直接精确输入；失焦或回车后自动保存。
- 不增加额外“保存”按钮；沿用 SillyTavern / TauriTavern 原有 input/change 保存链路。
- （v1.16.3）写词套装改成一列气泡：点一下换上；按住右边 ≡ 上下拖排顺序（常用的拖到下面）；「＋ 新建一套」从空白模板起一套，名字默认「我的套装 N」；「删除这个套装」能删自己加的，也能删内置的（内置的只是藏起来，下面点「恢复」找回）。序号按位置现排。
- （v1.16.4）查代码修的几处小毛病：新角色出场、改完长相弹的提示，原来让人去「扩展 → 自动配图 → 角色长相」找，现在指向魔法棒「看定妆照」；打开酒馆时自动挂世界书可能连跑两遍（卡里的书导两次、提示弹两次），改成排队一个一个来；魔法棒菜单的刹车停手那 10 秒里关掉扩展，到点不会再回来改菜单。
- （v1.16.5）面板整理：说明文字收进 ⓘ 小圆圈，点一下才弹出来；提示词要点「保存」才存，「取消」改回去，改了没保存会亮「● 没保存」，换风格或关窗口前先问；正在用的那套写「✓ 正在用」；按钮改成大白话（提示词风格、复制一套、恢复原版、找回删掉的、给最后一条补张图）；自动配图设置和魔法棒菜单面板里的勾选框跟「用户设置」页一样，手机上按住半秒才切换；「删掉这个角色」先问一句。
- （v1.16.6）更新完自动刷新换了个办法：酒馆「更新完叫扩展一声」那个接口在手机上没被叫到，现在点完更新按钮，扩展自己每秒看一次自己的版本号（最多 1 分钟），变了就弹「酒馆拓展更新好了，2 秒后自动刷新」并刷新。装上这版以后，下一次更新才看得到效果。

v1.8.1 持续优化，仅在粗指针/触摸环境启用，PC 端继续使用官方布局。

实现原则：

- 不改 World Info JSON、字段、扫描、触发、递归、注入和保存逻辑。
- 不复制官方 input / select / textarea；尽量只移动原 DOM 和增加布局 wrapper。
- 条目列表卡片化：标题优先占宽，可显示两行；移动/复制/删除与启用状态继续保留。
- 展开单条后进入移动端“编辑条目”视图：名称、正文、激活策略、概率、注入位置、深度、顺序和角色/标签过滤优先显示。

- “长文本模式”只通过 class 放大当前官方正文编辑器，不创建第二份正文状态；再次点击恢复普通编辑。
- 搜索、分页、新建等导致 `.world_entry` 重建时，通过 MutationObserver 幂等重新应用布局。
- 不新增自定义保存按钮；继续依赖 TauriTavern 官方 input/change 与 saveWorldInfo 链路。

### v1.8.3 字段说明

- **顺序（插入优先级）**：对应官方 World Info 的 Insertion Order。多个条目同时激活时，数字越大越靠近上下文末端；例如 100 会排在 250 前面。预算不足时，常驻条目优先，其后也优先考虑较大的 Order。
- **激活概率（触发后生效率）**：触发条件满足以后，本条最终被激活的概率。
- **激活策略（触发方式）**：常驻 / 普通关键字触发 / 向量化等官方条目状态选择。

- 🟢 普通（关键词触发）

- 结果显示在输入框上方的气泡里：**复制** 只复制总结正文；**重新生成** 再总结一次；**关闭** 收起。聊天没有新消息时再点“总结全文”直接显示上次结果，不重复消耗。
- 对话超过模型上下文时，自动只取最近的部分并在气泡里注明。

### v1.8.23 修复总结读不到聊天内容、字数可调

- 清理更彻底：去掉任意长度的 HTML 标签、注释、变量更新代码（UpdateVariable 等），只把剧情正文交给模型；清理后若几乎没有正文，直接提示，不再发送空记录。
- 提示词改为：这是虚构的角色扮演故事，把故事里已经发生的事当作事实整理下来；记录不完整也要尽量总结，不拒绝、不解释。
- 总结气泡新增 **字数** 拉杆（1000～3000，步长 100），也可直接填数字；设置会记住，调整后点“重新生成”即按新字数总结。
