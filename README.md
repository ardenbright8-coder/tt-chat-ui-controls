# 聊天显示控制 v1.5（SillyTavern / TauriTavern）

目前包含三类控制：

1. **聊天正文颜色**：只改消息正文。
2. **聊天正文字体**：在 UI 主题页直接下拉切换。
3. **背景图片模糊强度**：只模糊最底层背景图；原生“模糊强度”继续作为 UI 模糊。

## 字体

四款字体文件已随扩展提供：霞鹜文楷 GB、霞鹜臻楷 GB、小赖字体、悠哉字体。
保留“跟随主题”，移除仅有字体名称、未提供文件的 16 个选项。
旧设置若选了已移除项，自动回到“跟随主题”。

首次选择会显示“正在加载”，加载成功后立即切换现有正文，无需刷新。
加载失败时保留之前的字体并显示错误；快速连续切换以最后一次选择为准。
若失败，请确认扩展中的 fonts 文件夹已完整更新，再刷新页面重试。
角色名、输入框和其他 UI 的字体不受该选项控制。

字体按需从酒馆服务器读取，无需联网访问外部字体 CDN，也无需充值或安装系统字体。
全部使用 SIL OFL 1.1，来源、许可证及社区反馈见 [fonts/README.md](fonts/README.md)。

## 使用位置

TauriTavern：

**用户设置 → UI 主题 → 聊天正文颜色 / 聊天正文字体 / 背景图片模糊强度**

## 更新

仓库安装地址：

`https://github.com/ardenbright8-coder/tt-chat-ui-controls.git`

已经安装旧版时，在扩展管理中对“聊天显示控制”执行更新即可。

更新完成后刷新页面一次以载入新版本。此后在“聊天正文字体”下拉框中切换无需刷新。
本次仅修改字体选择与字体加载，未调整已有背景模糊、颜色或横幅逻辑。
