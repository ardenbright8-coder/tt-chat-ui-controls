# 酒馆拓展 v1.8.16（SillyTavern / TauriTavern）

目前包含三类显示控制、一套手机版防误触，以及移动端世界书界面优化：

1. **聊天正文颜色**：只改消息正文。
2. **聊天正文字体**：在 UI 主题页直接下拉切换。
3. **背景图片模糊强度**：只模糊最底层背景图；原生“模糊强度”继续作为 UI 模糊。
4. **手机版防误触**：滑块必须明确横向拖动才改值；单点、轻触和上下滚动不改值。用户设置里的布尔开关在手机端改为长按确认：单点不改值，在复选框上静止长按约 500ms 才切换。
5. **世界书移动端 UI**：把官方 World Info 现有 DOM 在手机上重排为卡片列表、单条常用编辑、高级参数折叠和长文本专注编辑。
6. **阅读旧消息时保持位置**：向上翻阅后发送消息时，挡住聊天自动跳底；一旦手指、鼠标或键盘开始手动翻阅，立即解除本次位置保护，随时都能继续上下滑动。若发送时已在底部，沿用酒馆原有的自动滚动设置。切换聊天时解除位置保护。

## 手机版防误触与自动保存

仅在粗指针/触摸环境启用，PC 保持原来的鼠标交互。

- 滑块按下后先等待约 10px 的方向判断。
- 上下移动优先判定为页面滚动，本次手势直到抬手都不能再切换成调参。
- 横向移动必须明显占优（约为纵向位移的 1.2 倍）才进入滑块模式。
- 单点轨道、轻微触碰不会改变数值。
- 横向拖动时实时预览；手指抬起后自动提交一次最终值。
- 用户设置里的布尔开关采用长按确认：必须按住实际复选框约 500ms，且期间移动不超过约 10px，才切换一次并自动保存；单点、轻触、上下滚动均不改值。
- 数字输入框可直接精确输入；失焦或回车后自动保存。
- 不增加额外“保存”按钮；沿用 SillyTavern / TauriTavern 原有 input/change 保存链路。

## 世界书移动端 UI

v1.8.1 持续优化，仅在粗指针/触摸环境启用，PC 端继续使用官方布局。

实现原则：

- 不改 World Info JSON、字段、扫描、触发、递归、注入和保存逻辑。
- 不复制官方 input / select / textarea；尽量只移动原 DOM 和增加布局 wrapper。
- 条目列表卡片化：标题优先占宽，可显示两行；移动/复制/删除与启用状态继续保留。
- 展开单条后进入移动端“编辑条目”视图：名称、正文、激活策略、概率、注入位置、深度、顺序和角色/标签过滤优先显示。
- 主要关键字、可选过滤器、扫描深度、大小写、整词、组、递归、自动化 ID、粘性/冷却/延迟等仍使用官方原控件，默认收进“高级设置”。
- “额外匹配来源”保留官方原 drawer，单独显示。
- “长文本模式”只通过 class 放大当前官方正文编辑器，不创建第二份正文状态；再次点击恢复普通编辑。
- 搜索、分页、新建等导致 `.world_entry` 重建时，通过 MutationObserver 幂等重新应用布局。
- 不新增自定义保存按钮；继续依赖 TauriTavern 官方 input/change 与 saveWorldInfo 链路。

### v1.8.3 字段说明

- **顺序（插入优先级）**：对应官方 World Info 的 Insertion Order。多个条目同时激活时，数字越大越靠近上下文末端；例如 100 会排在 250 前面。预算不足时，常驻条目优先，其后也优先考虑较大的 Order。
- **激活概率（触发后生效率）**：触发条件满足以后，本条最终被激活的概率。
- **激活策略（触发方式）**：常驻 / 普通关键字触发 / 向量化等官方条目状态选择。


### v1.8.4 激活策略选择器

手机端激活策略下拉仍然使用官方原生 `select`，不替换控件、不改值，只修改三项的显示文本：

- 🔵 常驻（始终注入）
- 🟢 普通（关键词触发）
- 🔗 向量（语义匹配）

因此 Android WebView 弹出的白色原生选择框会直接显示说明文字；关闭下拉后当前选中项也会显示对应说明。功能、保存和数据结构完全不变。


### v1.8.5 常用参数说明

只增强移动端外层“常用参数”，高级设置保持原样。

- **注入位置 !**：解释角色定义前/后、示例消息前/后、作者注释前/后、@D 系统/用户/AI 与 Outlet 的区别，并说明“注入位置”和“顺序”不是一回事。
- **注入深度（仅 @D） !**：说明 0/1/2 分别插到聊天历史多近，并明确它不同于高级设置里的“扫描深度”。
- **顺序（越大越靠后，通常影响更强） !**：举 100 / 250 的例子，并说明这不是数学权重倍数。
- **激活概率（命中后生效概率） !**：说明 100% / 50% / 20% 的含义，并强调它只决定“进不进”，不决定注入后的强弱。
- **激活策略（触发方式） !**：解释常驻 / 普通 / 向量。
- **绑定对象 / 角色过滤 !**：说明它看的是当前角色，而关键词看的是聊天内容。

同时，手机端“注入位置”的 Android 原生选择框直接显示更完整的选项说明，例如“@D ⚙️ 系统（按 system 消息插入聊天历史）”，但官方 option value / data-role / 保存逻辑全部保持不变。


### v1.8.6 编辑流程修正

- 修复返回列表后每条卡片出现返回箭头 / 重复标题 / 错版的问题：编辑工具栏只在当前编辑条目显示。
- 返回列表时记住进入编辑前的滚动位置与条目位置，关闭后尽量回到刚才那一条附近，不再直接跳到列表顶部。
- 单条编辑顺序调整为：**名称 → 大正文框 → 常用参数 → 高级设置 → 额外匹配来源**。
- 正文框移动到更靠前的位置，移动端最小高度提高到约 46dvh，优先满足长提示词阅读和修改。
- 底部新增 **取消 / 确定**：
  - **确定**：保留当前值并返回。TauriTavern 官方本身仍然按原 input/change 自动保存。
  - **取消**：把进入编辑页时记录的原控件值恢复，再通过官方 input/change 事件把原值写回；不建立第二套世界书保存逻辑。
- 顶部返回箭头等价于“保留当前修改并返回列表”；真正撤销本轮修改请使用底部“取消”。


### v1.8.7 返回位置与正文字号

  - 范围 14–32px；
  - 一旦手动调整，会通过 localStorage 记住这个移动端世界书正文大小，下次打开继续使用；
  - 只影响世界书“内容”编辑器，不改全局 UI 字号，不改 World Info 数据。

### v1.8.16 改名与世界书选字滚动修正

- 扩展显示名改为 **酒馆拓展**（旧名“聊天显示控制”），仓库地址不变，已安装的直接更新即可。

  - 宿主把内容框换成了带撤销/搜索/复制工具栏的代码编辑器（CodeMirror），上一版只盯着隐藏的原始文本框，所以限速从未生效；现在按当前实际获得焦点的编辑区判断。
  - 选字时不只内容框自己在滚，外层世界书面板也会被带着滚；现在内容框、编辑器滚动层、外层面板一起限速。

### v1.8.20 一键总结全文

- 左下角菜单（☰）里“继续”下面新增 **总结全文**。
- 点击后单独向当前模型发一次请求：暂停一切角色扮演，通读全部聊天记录，由模型自行判断关键点，整理成约 1000 字的剧情总结，不编造、不续写。
- 这次请求不带预设、不带世界书，也不会写进聊天记录，故事上下文不受影响。聊天里的状态栏代码块、思考过程、系统消息会先剔除。
- 结果显示在输入框上方的气泡里：**复制** 只复制总结正文；**重新生成** 再总结一次；**关闭** 收起。聊天没有新消息时再点“总结全文”直接显示上次结果，不重复消耗。
- 对话超过模型上下文时，自动只取最近的部分并在气泡里注明。


### v1.8.21 总结库、用总结开局、空白开局

- 左下角菜单新增 **总结库**：每条显示角色名、时间、字数，顶部可按角色名或内容搜索。
