# 聊天显示控制 v1.3（SillyTavern / TauriTavern 前端扩展）

在 v1.2 的基础上增加“聊天正文字体”下拉菜单，同时保留原来的聊天正文颜色与背景图片独立模糊。

## 功能

用户设置 → UI 主题：

- **聊天正文颜色**：只改变消息正文文字颜色。
- **聊天正文字体**：只改变消息正文，不动菜单、按钮、角色名、时间戳和输入框。
- 原生 **模糊强度** 显示为 **UI 模糊强度**。
- **背景图片模糊强度**：只模糊最底层 `#bg1` 背景图片。

## 字体下拉菜单

当前内置这些字体名称：

- 跟随主题（默认）
- 文渊宋体
- 思源宋体 / Noto Serif SC
- 霞鹜文楷
- 华文楷体
- 方正楷体简体
- 方正新楷体_GBK
- 汉仪书宋一简
- 方正北魏楷书_GBK
- Aa恋恋樱落
- 汉仪诗楷简

注意：下拉菜单负责切换 `font-family`。对应字体必须已经被主题、扩展或系统加载；没有加载时浏览器会使用后备字体。后续如果把合法可再分发的字体文件放进扩展，可直接通过 `@font-face` 绑定到这些选项。

## 安装

TauriTavern → 扩展 → 安装扩展，粘贴本仓库 Git URL。

更新已有安装时，在扩展管理页对本扩展执行更新即可。
