# 聊天显示控制 v1.4（SillyTavern / TauriTavern）

目前包含三类控制：

1. **聊天正文颜色**：只改消息正文。
2. **聊天正文字体**：在 UI 主题页直接下拉切换。
3. **背景图片模糊强度**：只模糊最底层背景图；原生“模糊强度”继续作为 UI 模糊。

## 字体

### 扩展直接可用
这两款由扩展联网加载，不要求 Android 系统安装字体：

- 霞鹜文楷 GB
- 霞鹜臻楷 GB

两者均来自 lxgw 官方 GitHub 项目，许可为 SIL OFL 1.1。许可证副本放在 `fonts/` 目录。

### 菜单中保留的其他字体
下拉菜单还包含你列出的这些字体名称：

- Aa恋恋樱落
- 樱落诗楷
- 汉仪诗楷简
- 汉仪书宋一简
- 华康楷体W5
- 方正楷体简体
- 方正新楷体_GBK
- 方正大标宋简体
- 方正粗楷简体
- 方正姚体_GBK
- 方正北魏楷书_GBK
- 兰米粗楷简体
- 三级朴宋简体
- 华文楷体
- 文渊宋体
- 思源宋体 / Noto Serif SC

这些没有随公共仓库分发字体二进制；若主题或系统本身已有对应字体，选择后会直接使用，否则自动回退。

## 使用位置

TauriTavern：

**用户设置 → UI 主题 → 聊天正文颜色 / 聊天正文字体 / 背景图片模糊强度**
